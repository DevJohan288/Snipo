No necesitas aprender todas las herramientas a la vez. Avanza por fundamentos, practica cada etapa con proyectos pequeños y elige una especialización cuando tengas una base.

## 1. Aprende cómo funciona la web

Familiarízate con navegador, servidor, URL, HTTP, HTML, CSS y JavaScript. Aprende a usar un editor, las herramientas de desarrollo del navegador y Git para guardar cambios.

## 2. Construye fundamentos de frontend

1. **HTML:** elementos, atributos, formularios y semántica.
2. **CSS:** selectores, modelo de caja, Flexbox, Grid y diseño responsive.
3. **JavaScript:** sintaxis, tipos, variables, condiciones, ciclos, funciones, arreglos, DOM y eventos.
4. **Accesibilidad y UX:** navegación por teclado, contenido comprensible, jerarquía visual y pruebas con personas.
5. **Herramientas:** depuración del navegador, Git y control de versiones.

Convierte lo aprendido en páginas y pequeñas aplicaciones antes de adoptar un framework. Más adelante, elige React, Vue o Angular según el proyecto y aprende uno a la vez; sus conceptos y ecosistemas no son intercambiables por completo.

## 3. Amplía hacia backend

Aprende a diseñar APIs (por ejemplo REST), manejar errores HTTP, validar entradas y proteger datos. Estudia SQL y bases de datos; luego compara NoSQL cuando el caso lo justifique. Comprende autenticación y sesiones antes de implementar una solución concreta. Un ORM puede ayudar, pero no sustituye conocer las consultas ni la seguridad de los datos.

## 4. Practica lógica y resolución de problemas

Divide un objetivo grande en tareas pequeñas, escribe los pasos antes de codificar y prueba cada caso con entradas distintas. Practica estructuras de datos y algoritmos con ejercicios breves. Cuando te atasques, consulta documentación, comunidades y código de proyectos; intenta explicar con tus palabras qué hace la solución.

Mantén el hábito de construir proyectos, leer código ajeno y revisar qué podrías simplificar. Optimiza rendimiento cuando puedas medir un problema concreto: imágenes adecuadas, carga diferida donde corresponda y reducción de recursos innecesarios son buenos temas para explorar.

## Recursos para practicar

- [MDN Web Docs](https://developer.mozilla.org/): referencia de HTML, CSS, JavaScript y APIs web.
- [freeCodeCamp](https://www.freecodecamp.org/): cursos y retos prácticos de desarrollo web.
- [W3Schools](https://www.w3schools.com/): tutoriales y ejemplos interactivos para empezar.
- [Scrimba](https://scrimba.com/): cursos interactivos de programación; algunas rutas pueden ser de pago.
- [CSS-Tricks](https://css-tricks.com/): artículos y guías de CSS.
- [SQLBolt](https://sqlbolt.com/): lecciones prácticas de SQL.
- [Learn Git Branching](https://learngitbranching.js.org/): visualiza ramas y operaciones de Git.
- [VisuAlgo](https://visualgo.net/): visualizaciones de estructuras de datos y algoritmos.
- [HackDesign](https://hackdesign.org/): lecciones de fundamentos de diseño.
- [Vue School](https://vueschool.io/): recursos para Vue; revisa qué cursos son gratuitos.
- [CryptoZombies](https://cryptozombies.io/) y [LearnWeb3](https://learnweb3.io/): material especializado en blockchain y Web3, útil como ruta opcional.

La disponibilidad, el contenido y los planes gratuitos de estas plataformas pueden cambiar. Contrasta los tutoriales con documentación oficial y no necesitas completar todas las listas para empezar a crear.
